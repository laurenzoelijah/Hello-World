<ins>**Running the Project**</ins>\
To run the program:
Download or clone the repository.
Open the project folder in Visual Studio Code.
Open the Python file you want to run.
Make sure Python is installed.
Run the file using Visual Studio Code.
The program can also be run through the terminal with:
python filename.py
Replace filename.py with the actual name of the Python file.
